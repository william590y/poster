About 1.75 minutes. Lead: every evaluation dataset becomes a byte stream, scored zero-shot as next-byte loss in bits per byte. Anchor the two reference lines: 8 bits/byte is a uniform guess over 256 bytes; 3 is the floor for a predictor that knows DNA uses only 8 symbols (App. B.5, p.27). No gradient step on any eval dataset (p.8), synthetic ones included. Melody (B.4, Fig. 10 shown): 40 'highly recognizable' public-domain pieces from Mutopia, melody only, 16th-note grid. Codes: 0-127 pitch onset, 128 hold, 129 pause, 130 end, one note per cell. Beethoven's Fifth: 67,128,67,128,67,128,63, then seven 128s. Text (B.1): DCLM, UTF-8, fixed windows (Fig. 8). Images (B.2): CIFAR-10 test batch; planar CHW is described in B.2 text, while Fig. 9 shows HWC only. Speech (B.3): Speech Commands, floor((s+32768)/256); 255 bytes = 15.94/31.88/63.75 ms at 16/8/4 kHz. [mine] Encodings are hand-chosen, so bits/byte is not one common task. App. B documents 7 sources. Nine Fig. 7 datasets have no entry: Common Crawl, Kolmogorov text, GitHub Python, arXiv math, LibriSpeech, ESC-50, MusicNet, glibc rand, Arithmetic. MusicNet (Thickstun, Harchaoui and Kakade 2017) is in Fig. 2 but not in the references. Moved off the slide, in the outline's words. Hyperparameter line in full: 'No gradient step on any eval dataset (p.8); DCLM and DNA also selected hyperparameters (see Method)'. The slide drops only '(see Method)'. Encodings line in full: 'Six byte encodings, each defined in App. B: text (UTF-8), images (CIFAR-10, HWC or planar), speech (PCM16 -> 1 byte per sample), melody (16th-note grid), DNA, code'. The slide's DNA chip adds '8-symbol alphabet' and the code chip says 'ASCII source bytes': App. B.7 keeps the C source's original ASCII byte values, and B.6 encodes Metamath set.mm the same way (both p.27; detail from the paper, not the outline). Record lengths in full: 'speech, Metamath, C: 255-byte records at context 256; DNA: 255-symbol records; melody: 255 bytes = 63.75 quarter notes (B.4), pieces truncated to 4,095 bytes; DCLM window not stated; CIFAR image = 3,072 bytes'. Training context: 4,096. The slide keeps speech, Metamath, C, DNA, CIFAR and the 4,096 training context; the melody and DCLM details are only here. Point to make: most eval records (255 bytes or symbols) are far shorter than the 4,096-token training context.
