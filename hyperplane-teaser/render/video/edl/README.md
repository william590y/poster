# EDL schema (teaser.html)

One engine page, many edits: `teaser.html?edl=<name>` loads `edl/<name>.json`. Everything that changes between the short teaser and the long version lives in the EDL. The engine holds only the look and the logo geometry.

**rev2:** the engine is now `fx/core.js` plus modules (`fx/index.json`); the r1-r7 item types below live in `fx/legacy.js` unchanged. New work goes in the module files: read **Modules** at the end of this file first.

## Pipeline
```
python3 render/video/prep_clips.py short            # clip frames -> render/video/cache/<item-id>/%05d.jpg (+ meta.json); images -> cache/<id>/image.jpg
python3 render/video/render.py sheet short 0.5 2 4 13.2 20.4 [--guides] [--debug] [--thumb 300]
python3 render/video/render.py still short 13.1333 [out.png]
python3 render/video/render.py video short [out/short-silent.mp4] [--from S --to S] [--png]
python3 render/video/render.py cues short [--json]   # speech placements for the audio mix
python3 render/video/render.py beats long --from 0 --to 8 [--eighths]   # rev2: one frame per hits.json beat (the critics' rhythm view)
python3 render/video/render.py video long --workers 2                    # rev2: N Chromium pages in parallel (no gain on this shared box)
python3 render/video/check/beatcheck.py long --render --from 0 --to 12   # rev2: per-beat change, weak beats, dead stretches (+ PNG)
python3 render/video/check/coverage.py long                             # rev2: imagery per frame, reveal modes, lyrics, safe zone
python3 render/video/check/regress.py snap|compare|det ...              # rev2: engine regression and determinism
python3 render/video/mix.py long --video out/long-silent.mp4   # WAVs (song, clean, speech) + the muxed deliverables
```
EDLs: `short.json` (the spliced intro cut, 35.6 s: song 6.10 -> 26.477, splice, 65.188 -> 80.411; generated by `edl/make_short.py`,
which writes its own montage since r4 and takes the grids, look and drop formation from `short-v1.json` (the earlier 20.65 s
teaser) and the refrain-b and instrumental items from `long.json`), `long.json` (the drop cut, song 19.232 -> 80.432; generated by `edl/make_long.py` from
`edl/long-beats.json`, so edit the script and re-run it, then re-run prep).
- **Frame i is drawn at t = i/fps exactly.** The frame count is round(duration × fps).
- `--guides` overlays the approximate Reels/TikTok text-safe box (y 250 to 1574, x 60 to 1014) and the right button rail (x > 960, y > 1000).
- `--debug` labels each item with its id and times, and flags `"verified": false`.
- `video` refuses to run if clip frames are missing, and prints any unverified items.
- The cache, `sheets/` and `out/` contain copies of the clips. They are git-ignored; never commit them.

## Top level
| key | meaning |
|---|---|
| `fps`, `width`, `height` | 30, 1080, 1920 |
| `duration` | edit length in seconds (`window.DURATION`) |
| `audio` | for the mux step only (the page ignores it): `song`, `songStart` (song second at edit 0), notes |
| `song` | mixer form (overrides `audio`): `{file, segments: [{in_s, out_s, at}], xfade_ms, xfade_shape, bars, bar_tol_ms, fade_in_s, fade_out_s, gain_db, max_out_s, clean}`; see **Song segments and the clean variant** below |
| `mix` | overrides of mix.py's DEFAULTS, e.g. `{"limiter_max_gr_db": 4.0}`; `speech_limiter_max_gr_db` sets that cap for the speech-only (no-song) mix alone (default: the same as `limiter_max_gr_db`) |
| `outputs` | deliverable paths for `mix.py --video`: `song`, `clean`, `no_song` |
| `themes` | `[{t0, t1, theme: "light" | "dark"}]`: items starting in a range get that text theme (ink on cream vs light on dark); an item's own `theme` wins |
| `look` | `ground` (montage background), `red` (accent), `dim` (secondary text) |
| `layout` | overrides of the engine's default layout. Commonly `clipBox` {x,y,w,h} (default 0,330,1080,940); `prep_clips.py` reads it too. Also `stamp` (default x 60, y 300: below the app header), `meta` / `name` (px of the secondary mono lines and stamp names, default 38 / 40), `caption`, `quote`, `headline`, `stack`, `text` (see `LAYOUT` in teaser.html). |
| `grids` | named beat grids in **edit seconds**: an explicit array, or `{origin, period, count, start?, snap?, tol?}` meaning beat i = origin + (start+i)·period, snapped to the nearest `snap` time within `tol` |
| `stacks` | optional per-stack layout for headline stacks: `{ "<id>": {y0, y1, gap, dim, align} }` |
| `items` | the edit, drawn in order (later items sit on top). `"enabled": false` skips an item. |

## Time references (any `t0`, `t1`, `at`, cue)
- `12.5`: edit seconds.
- `"riff:8"`: beat 8 of grid `riff`. Fractions interpolate, so `"riff:8.5"` is the 8th note after beat 8. Indices beyond the array extrapolate.
- `"pre:3+0.05"` / `"pre:3-0.05"`: a beat plus an offset in seconds.
- `{"at": "riff:4", "off": -0.033}`: the same thing, in object form.

In `short.json`, `riff` is the measured riff grid (beat 0 = the drop, 13.132). `pre:k` counts k beats *before* the drop (`pre:3` = 11.680).
`beat` is the riff (beats 0-15) followed by the post-splice beats, so `bar:4` = song bar 24 ("golden years", edit 20.900), `bar:7` = "God, it's
brutal out here" and `bar:8` = the instrumental (song 73.42, edit 28.609). After the splice, short edit = long edit - 25.579 = song - 44.811.
In `long.json` (edit = song - 19.232): `riff` is the same measured riff, `beat` continues it with song/bars.json's beats snapped to the measured onsets, and `bar:k` = `beat:4k` (bar 4 = verse 1, bar 12 = chorus, bar 20 = refrain, bar 27 = "God, it's brutal out here", bar 28 = the instrumental).

## Fields every item accepts
`id`, `type`, `t0`, `t1` (visible for t0 ≤ t < t1), `enter`/`exit` (`"cut"` default, `"fade"`, `"flicker"`, `"slam"`, `"rise"`, `"drop"`; exit also takes `"push"`, or `{style, dur, ...}`; framed items also take the **frame motions** below),
`theme` (`"light"` / `"dark"`, else from `themes`), `textDelay` (framed items: seconds before their text rises in), `bg` (full-frame fill behind the item), `hit` (camera-shake amplitude at t0, or `{amp, decay}`), `shakes` (`[{at, amp, decay}]`: extra camera hits inside the item's life, e.g. a beat-locked event during a long hold), `flash` (`{opacity, decay, color}` at t0), `z`, `verified` (false = still to check; flagged by `--debug` and `render.py video`), and `_note` (free text, ignored).
Long r5: `kicks` (`[{at, s (1.02), dur (0.16)}]`: beat-locked scale bumps of the WHOLE item, frame, text and attribution together: it jumps to `s` on the beat and eases back over `dur`) with `kickOrigin` (`[x, y]` px, the bump's centre; default 540, 960). Give every item of one card the same list and origin so they move as one (make_long.py's `kicks(bar0)` helper: 2 % on beat 3 of each bar, 3.5 % on the second bar's downbeat). Opt-in: items without it render exactly as before.
Long r6: `skipIn` (`[edl names]`): the item is skipped when the page renders one of those EDLs (`teaser.html?edl=<name>`). For items that make_short.py imports from long.json but the long cut no longer shows (`rf-stargate`, `rf-guardian`: `"skipIn": ["long"]`); the short's copies carry the field and still draw. prep_clips.py still prepares them.

## Item types
- **clip**: pre-extracted footage plus an optional stamp and caption.
  - `src` (relative to the project root) and `in` (source second shown at t0). `speed` defaults to 1.
  - Source crop, used by prep: `crop` {x,y,w,h} in source px (keep the clipBox aspect), or `srcFocus` [fx,fy] + `srcZoom`.
  - `grade` {sat, contrast, brightness, gamma, sharpen, grain, deinterlace} is applied in ffmpeg by prep. Edit it, then re-run prep.
  - `zoom` [z0,z1] + `focus` [fx,fy]: a slow push-in inside the box, applied in the page.
  - `box` overrides `layout.clipBox`. `frames` is the cache folder name (defaults to the id).
  - `stamp` {year, name, role, x?, y?, yrPx?, w?} (`yrPx`: a smaller year chip, default 58 px; r5 `w`: max width of the name/role
    column, so a long role wraps under the name instead of running off the frame). Mono attribution, role, source and label lines are 38 px and stamp names 40 px by default
    (`layout.meta` / `layout.name`, or per item `meta` / `name_px`; the short's montage keeps 30 / 34 under its clip box).
  - `caption` {text, hl, words, reveal, y}. `words` are `[{w, s: source-second}]` or `[{w, t: item-local s}]`. Words appear as they are spoken (`reveal`: `"words"` (default), `"dim"` or `"all"`). `hl` is a substring or a list of substrings, set white on red.
    r4: `dimHl` (with `reveal: "dim"`) is the not-yet-spoken opacity of highlighted words (default 0.22 like the rest; e.g. 0.8 so a
    hook phrase reads on the first frame); `hlKeep: true` keeps each highlighted phrase on one line. r5: `dimOp` is the
    not-yet-spoken opacity of the other words (default 0.22).
  - r5 `punch` `[{at, z (1.03), dur (0.08)}]`: quick punch-ins on a word (they multiply the slow `zoom` and stay; pair with
    `shakes` for a hit). `freeze` (a time): the picture holds on the frame at that moment, e.g. after the last heard word of a
    trimmed line, so no silent mouth is shown.
  - r6 `zoomEase`: the curve of the slow `zoom` over the item's life: `"io"` (default, ease in-out: the first and last moments barely
    move), `"out"` (moves from frame 0 and settles; the short's hook) or `"lin"`. `snap` {z (1.08), dur (0.25)}: the picture starts z
    times larger on the item's first frame and settles onto the push over dur (a snap-in on a cut). Both opt-in.
  - `source` is a small attribution line under the caption.
  - r7 `sub` {text, size (40), w, gap (16), color}: a small Newsreader italic line between the caption and the source line, for
    words that are NOT heard (e.g. how the speaker's sentence goes on after the audio stops: the short's Amodei, "“…and a 75% chance
    that things go really, really well…”"). It is never word-lit, so it does not read as a subtitle; the caption stays exactly
    what is heard.
  - `audio` {in, out} in source seconds is the speech window for the mix. It plays at edit `t0 + (audio.in − in)/speed` and may start before the picture (a J-cut).
    r5 `lcut` (s): a deliberate L-cut allowance (the last word runs on under the next item); mix.py's "speech runs past the
    clip's picture" warning then fires only beyond it.
  - `key` (r4; **removed in rev2**: BUILD.md "keep the original footage". prep_clips.py now ignores the field with a warning and
    `keying.py` stays as an unused tool; the text below is history): replaces the background with a plain dark radial ground before the grade (`render/video/keying.py`: u2net person
    segmentation from `clips/models/u2net_human_seg.onnx`, git-ignored, plus colour rules). `{model, region: [x0, y0, x1, y1]
    (source px given to the segmenter, covering the crop), walls: [{hue: [lo, hi], sat, val}] (wall colours that are always ground),
    letters: [[y0, y1]] (rows of white lettering: white blobs there that touch the wall are ground), white {sat, val}, erode, feather,
    smooth (temporal median, frames), bg: [centre, edge], bgCenter [fx, fy], bgRadius}`. Made for stage walls that carry branding
    (the short's Amodei shot: rows of AXIOS logos behind his head). prep_clips.py re-keys when any of it changes.
- **caption**: a caption with no picture of its own, for a line that runs across several clip items (cuts, punch-ins). Takes `text`, `hl`, `words: [{w, at: <time ref>}]`, `source`, `y`, `w`, `size` and `srcGap` (px between caption and source line, 18).
  r6 (long): `serif: true` sets the caption as a pull-quote (Newsreader italic, sentence case, no uppercase) instead of mono, e.g. the long cut's opening hook; the red highlight chip, `reveal`, `dimOp`/`dimHl` and `hlKeep` work as before.
  r4: `srcInline: true` sets the source line on the red rule's line (right of it) and the caption under it, saving a row; also `lh`, `dimHl`, `hlKeep`.
- **stamp**: just the year tag and name/role row (`stamp: {year, name, role}`), e.g. above a headline stack.
- **quote**: a card for a quote with no usable footage.
  - `stamp`, `text` or `parts: [{text, at, per}]` (a quote can land in pieces; `per` = seconds per word).
  - `hl`, `size`, `big` (a huge figure such as `"25%"`, with `bigSize`), `source`.
  - Wrap the verbatim text in quotation marks yourself, and mark trims with ….
- **headline**: a serif headline with a mono `OUTLET · MON D, YYYY` line under it. Takes `outlet`, `date`, `text` (exact, never reworded), `size`, `hl` (exact substrings marked red) and `style` {x, w, cy}.
  `hlAt` (a time) makes the highlight wipe on left to right at that moment (over `hlWipe` s, 0.18) instead of landing with the
  headline (r6: on the 2-frame inverted landing, the not-yet-wiped words are set in the paper's ink; they were white, i.e. invisible); r5 `dimRest` (opacity, e.g. 0.3) sets the text outside the exact `hl` spans dimmer, so a dense headline reads as its
  highlighted phrase while the whole verbatim headline stays on screen; `zoom` [z0, z1] is a slow push-in around the block's centre over the item's life (same curve as a shape's zoom).
  - Every headline sharing a `stack` id is laid out once, top to bottom, centred in the stack's region. Each appears at its own t0 (inverted for 2 frames, then a quick slam). Earlier ones dim to `stack.dim` when a newer one lands.
- **text**: free text such as the breath line.
  - `text`, or `words: [{w, at, how: "drop"|"cut"}]` to land word by word.
  - `style` {y, size, font, weight, italic, color, tracking, upper}. The default is Newsreader italic, white, centred.
- **logo**: the Kandinsky formation (geometry from `render/hp/kand_e.html`).
  - `grid` + `beat0`: beat 0 of the formation = `grid[beat0]`.
  - `layout` {y, scale} places the 1500-unit cover. Default `{y: 400, scale: 0.72}`; the final frame matches `brand/hyperplane-cover-3000.png`.
  - `cues` {part: beat-or-time} overrides the default choreography (`LOGO_CUES`). Parts: `plane`, `dots`, `sort`, `pink`, `black`, `core`, `smallO`, `blue`, `teal`, `square`, `target`, `arc`, `normal`, `margin`, `chk`, `nabla`, `wordmark`, `tilt`, `kicker`.
  - `hits` [{beat, amp, decay}] are camera shakes; `flashes` [{beat, opacity, decay}].
  - `pulse` {from, to, amp, accents: {beat: ×}} is the whole-art kick on beats.
  - The formation's cream background is `bg`.
- **grain**: animated film grain over everything (not shaken). Takes `opacity` (0.035 ≈ 12 Mbps at CRF 17; every +0.01 costs about +5 Mbps), `size` (particle px) and `hold` (frames per pattern).
- **vignette**: a radial darkening, with `opacity`.

## Long-cut types: frames, the plane band, pull-quotes, the logo breaking apart and reassembling
**Frames.** A `frame` is a shape cut from the broken logo that holds content: `{shape: "circle" | "square" | "rect", x, y, w, h}`
or `{cx, cy, r}` (circle) or `{cx, cy, w, h}`, plus `ring` (colour), `ringW` (px), `fill` (colour behind the content),
`radius` (corner px) and `rot` (deg). Items with a frame animate the frame itself:
- enter `{"style": "morph", "from": "logo:square", "dur": 0.26}`: the frame grows out of a logo piece (its position, size,
  rotation and colour, which fades off to reveal the content). Pieces: `band`, `square`, `pink`, `black`, `core`, `smallO`,
  `blue`, `teal`, `target`, `chk`, `nabla`, `wm`; `logo:` is the first logo item, or name one by id (`logo-form:pink`).
  `delay` (s) holds the frame at the piece's geometry first (a stay-behind piece at a logo break), then morphs over `dur`.
- enter `"pop"` (scale up with overshoot), `"slam"` (1.18 -> 1), `{"style": "fly", "from": "left" | "right" | "up" | "down" | "axis" | [x, y], "dist", "spin"}`, `"fade"`, `"flicker"`.
- exit `{"style": "collapse", "dur", "spin"}` (shrinks to a point), `{"style": "fly", "to", ...}`, `"fade"`, `"push"`, or
  `{"style": "morph", "to": "logo-re:black", "dur"}` (the frame shrinks into a logo piece and ends exactly on it; pair it with
  that logo's `cutIn` so the piece appears where the frame lands).
- The item's other text (stamp, attribution) rises in `textDelay` after it and leaves with the frame.

- **image**: a still (deck screenshot, photo) in a `frame`. `src` (absolute or project-relative), `crop` (source px
  `{x, y, w, h}` or `{x0, y0, x1, y1}`), `fit` (`"cover"` default, centred on `srcFocus`; `"contain"` with `pad`/`bg`;
  `"width"` = frame width at natural height, for `pan: [from, to]`, a vertical scroll as a fraction of the overflow),
  `grade` (same keys as a clip's, applied by prep; images default to no change), `zoom` [z0, z1] + `focus` (push-in),
  `oversample`, `stamp`, and an attribution line from `outlet` + `date` (or `source`), placed under the frame or at
  `srcPos` {x, y, w}. prep_clips.py writes `cache/<id>/image.jpg`; re-run it after editing crop/grade/frame.
- **clip** with a `frame`: the clip plays inside the shape (prep extracts it at the frame's size). A clip with no `audio`
  window is **muted**: under sung vocals give its words as a separate `pullquote`, not a caption.
- **shape**: an empty frame (a ring, a disc, a square) used as a card or an accent; takes `frame`, the frame motions and
  `zoom` [z0, z1] (a slow grow over its life, up to its exit). `resize` {at, dur (0.16), frame: {...}} grows (or shrinks) the
  card to a new rect at `at` with a small overshoot, e.g. a card that opens at content height and grows when more content lands.
- **band**: the logo's yellow plane band as an object: `band` {cx, cy, h (thickness), angle (-22), len, color, edge,
  edgeW}. enter `{"style": "morph", "from": "logo:band"}` (the logo's thin band thickens into it), `"slide"` (along the
  band, `from: "left"|"right"`), `"slam"`, `"grow"`, `"fade"`; exit `"slide"` (`to`), `"collapse"`, `"fade"`.
- **ticker**: a headline set inside a band at its 22 degrees: `text` (exact), `hl`, `outlet`, `date`, `size`; `band` is the id of
  a `band` item (consecutive tickers share it, each landing with a 2-frame ink flash) or an object for its own band (then its
  enter/exit move the band and the text together; prefer `slam` for an own band, so text and band land on the same frame).
  `style` {w (text width along the band, 860), pad, along, across, drift (px of slow travel along the band), invert,
  labelX (60), labelY, labelGap (16), labelStack (r4: outlet over date, a compact block that hugs the band's edge)}. r5: `dimRest`
  as on a headline (the text outside `hl` at that opacity); item-level `invert` (s, default 0.067) is the ink-flash length, e.g.
  0.06 for exactly two frames. Text that would not fit the band's thickness is set smaller (printed as info).
  The attribution `OUTLET · DATE` is NOT tilted: it is one straight 38 px mono line on the ground, left-aligned at `labelX`,
  its bottom-right corner just above the band's top edge (or at `labelY`). Highlights on the band are deep red `#8E1212`.
- **pullquote**: verbatim words styled as a quote (Newsreader italic; not a subtitle and not word-timed), with `name`,
  `year`, `role` and an optional `source` line (r5: or a header `stamp` {year, name, role, w?} at `layout.stamp`, like every other
  sourced item; it rises in with the quote and leaves with it); `hl` marks exact substrings (white on red on dark, red on light); `big`
  (a figure, `bigSize`, `bigDim` = the part set in the text colour), `label` (small red kicker), `upright` (roman instead of
  italic), `rule: false`, `style` {x, w, y | cy, size, lh, align: "left" | "center", mono (IBM Plex Mono text, e.g. model
  output), pre (keep the line breaks in `text`), and colours for a quote set on a filled tile: color (text and name),
  bigColor, bigDimColor, hlColor, hlBg (the highlight as a chip, e.g. cream on ink on a pink tile), dimColor (role/source),
  labColor, labSize (label px), bigMono (the big figure in IBM Plex Mono, e.g. model output)}, optional `frame` behind it.
  With `exit: {style: "collapse"}` the text shrinks and spins with its card (same curve and centre as a shape's collapse).
  Put the quotation marks and any … in `text` yourself.
  r6 (long): `hlAt` (time ref) + `hlWipe` (s, 0.18): the highlight lands at that moment instead of with the quote, a beat-locked event inside a long hold (Leike's 'breaking point' on bar 9, Amodei's 'the dream' on bar 13). Before it the words sit in the quote's own colour; a chip highlight (dark ground, or `style.hlBg`) wipes on left to right, a text-only highlight (light ground) changes colour at `hlAt`.
- **voice**: clip speech with no picture of its own (e.g. over the closing logo): `src`, `at` (edit time of `audio.in`),
  `audio` {in, out, ...}. The page draws nothing; mix.py treats it like a clip's audio window. Pair it with a `caption`.
- **logo** additions:
  - r5 `wmFrom`: the wordmark's scale on its slam frame (default 1.32; 1.1 keeps the whole word inside the frame).
  - `slam` [parts] (e.g. `["plane", "pink", "black"]`; also `core`, `blue`, `teal`, `smallO`): these land fully formed on their cue frame,
    scaled `slamFrom` (1.3, or {part: scale}, e.g. {"core": 2.3}) -> 1 over `slamDur` (0.1 s), instead of growing in. `pulse.from: 0` with an accent on 0 kicks the whole art on the hit.
  - `break` {at, dur (0.4), stagger (s per piece), lead (s the other pieces wait after the wordmark and kicker), hide: [pieces],
    hideAt, bgFade (0 = hard cut), bgDelay (s the cream holds first, so the wordmark leaves on cream), dist, hit}: at `at` every
    piece blows out from the art's middle (wordmark and kicker first; ink pieces fade early so they don't ghost on a dark
    ground). Pieces in `hide` vanish at `hideAt` because frames morph out of them (`band`, `square`). The cream `bg` fades
    over `bgFade` to whatever is underneath (e.g. a dark `color` ground listed before the logo).
  - `rehits` (r4, form mode): `[{beat, parts: [...], scale (1.16), dur (0.14)}]` beat-locked bumps of single pieces during a hold
    (`"dots"` = the six data points), kept until a piece starts to fly at a break. `push` `{from, to, z: [z0, z1]}`: a slow push-in
    on the whole cover between two beats (numbers are beats of the item's grid; give an edit time as a string, e.g. `"20.397"`).
    Flash `beat`s may also be time strings.
  - `mode: "assemble"`: the cover rebuilds from scattered pieces. The data points pop in one by one from `dotsAt`
    (`dotStagger` apart; or `dotsAt` is a list, one time per point, e.g. on the words of a sung line; `dotScale` (2.6) is their
    size before the sort), the plane slams in on beat 0 and sorts them, the shapes fly back fully formed and land on their
    cues (`LOGO_ASSEMBLE`: 8ths through bar 1), the wordmark slams on beat 3, the crossbar tilts, the kicker lands on beat 4,
    then it holds (the final frame is the cover composition). `flyDur`, `flyDist`, `cues`, `hits`, `flashes`, `pulse` override.
    `cutIn` [pieces]: these appear at home on their cue with no flight (a frame's exit morph delivers them). `bg` (default
    cream) can be `rgba(0,0,0,0)` so items listed before the logo (e.g. a held disc) show through under the points.

## Song segments and the clean variant (mix.py)
`"song": {"file": "song/brutal.mp3", "segments": [{"in_s": 19.232, "out_s": 80.432, "at": 0}], ...}`. Each segment plays song
`in_s`..`out_s` from edit time `at` (a number or a grid ref; omit it to follow on from the previous segment). Consecutive
segments must butt (out of one = at of the next) and crossfade over `xfade_ms` (default 20) centred on the splice, the audio
on each side running on by half the crossfade; `xfade_shape` "gain" (raised cosine, sums to 1: for cuts within one song) or
"power". With `bars` (a bars.json path) every inner splice point is reported against the bar/beat grid (`bar_tol_ms`, 30) and
flagged if it is off it. Splice on downbeats with matched beat phase and no vocal straddling the cut; William checks by ear.
`fade_in_s`, `fade_out_s` apply to the first/last segment; `max_out_s` refuses any segment that plays past it.
A clip's or voice's `audio` may carry `peak_rel_db`: a per-clip true-peak limiter that many dB over the clip's leveled loudness,
re-leveled afterwards (for a transient such as a mic thump that would otherwise force the whole mix quieter).
`"clean": {"dips": [[44.86, 45.25]], "ramp_ms": 12, "depth_db": null, "mode": "full" | "mid"}` writes
`song/mix-<name>-clean.wav` too: the song is dipped to silence (or `depth_db`) over each window given in song seconds, with
raised-cosine ramps just outside it; `"mid"` dips only the centre channel. `outputs.clean` is its deliverable.
The mixer warns when any clip speech overlaps a sung stretch of the song (SONG_VOICE in mix.py: the spoken line at 17.66 and
the sung vocals measured for the long cut), which is the audio rule for the long version.

## Page lifecycle
1. `fx/core.js` loads `fx/index.json`: eager vendor libs (rough, freehand), then the modules in order (`.css` as stylesheets).
   Modules run immediately and call `HP.register(...)`, `HP.registerFX(...)`, `HP.on(...)`, `HP.layoutDefaults(...)`.
2. The EDL is fetched (`?edl=<name>`), `look`, `layout`, `grids`, the song map and `song/hits.json` are set up, fonts are loaded
   (so `build()` may measure text), hooks `setup` run.
3. Items are constructed in EDL order (each gets a layer `<div class="layer">` in `#cam`, or in `#fx` with `overlay`), then the
   `fx` events are expanded and built, hooks `built` run.
4. `load()` of every item (await), every asset requested so far is awaited (`HP.assets.wait()`), then `layout()` with every layer
   displayed, hooks `ready`, `renderAsync(0)`, `window.__ok = true`.
5. `render(t)`: clear shared canvases, hooks `frame(t)`, camera transform on `#cam`, every item's `frame(t)` (hide/show, envelope,
   `draw`), every fx `draw`, hooks `post(t)`, the flash. `renderAsync(t)` first awaits every item's `prepare(t)` (footage frames).

## Time references
Any `t0`, `t1`, `at`, cue or word time accepts: a number (edit seconds); `"grid:i[+-off]"` (an EDL grid, as before);
**`"hb:i[+-off]"`** = beat `i` of `song/hits.json` (0 = the drop, song 19.232; prelude beats negative; `"hb:8.5"` = the 8th
after beat 8; `"hb:8.25"` a 16th); **`"song:s[+-off]"`** = song second `s`; `{"at": <time>, "off": s}`. `hb:` and `song:` map song
time to edit time through the EDL's `song.segments` (spliced cuts; a beat inside a cut is an error) or `audio.songStart`
(edit = song - songStart). A grid named `hb` or `song` would win (don't). The Python tools resolve the same refs (`timeref.py`).

`song/hits.json` (from the analysis workflow) is read as `{beats: [{i, t (song s), kick, snare, hat, accent, vocal, ...}],
vocal_intervals: [[s0, s1]], words: [...], sections: [{name, s0, s1}], period}`; indices may be implicit (then 0 = the beat nearest
`drop`). (Integrator, 11 Oct: the real `song/hits.json` is in place; every EDL uses it.) **Until it exists, `song/hits.stand-in.json` is used** (built from bars.json + full-map.json: flags are guesses; the page
prints `info: hb: beats from song/hits.stand-in.json (STAND-IN ...)`). The real file wins automatically as soon as it is there.

## The HP API (fx/core.js)
**Helpers.** `HP.u = {clamp, lerp, pr (progress of t through [t0, t0 + d]), smooth, el, sv, setA, esc, $, mulberry32, EPS, NS}`;
`HP.ease = {lin, iQuad, oQuad, ioQuad, iCub, oCub, ioCub, oBack(u, s = 1.9), oExpo, iExpo, oElastic, oSine, ioSine, smooth}`;
`HP.W` 1080, `HP.H` 1920, `HP.FPS`; `HP.COL` (the cover's nine colours: ink, cream, pink, orange, red, blue, teal, violet, yellow);
`HP.LAYOUT`, `HP.LOOK`, `HP.EDL`, `HP.ITEMS`, `HP.WARN` (blocks `render.py video`), `HP.INFO`.

**Randomness (never `Math.random`).** `HP.hash(...keys)` (uint32), `HP.rng(...keys)` (a generator), `HP.rand(...keys)` (one float),
`HP.range(a, b, ...keys)`, `HP.pick(arr, ...keys)`, `HP.noise1(key, x)` (smooth value noise). Key by item id, stroke index, beat
index. `HP.frameNo(t)`; `HP.boil(t, on = 2)` = a new seed every `on` frames (line boil on twos: `rng(id, HP.boil(t) % 3)`).
`Math.random` is trapped: inside `render(t)` it is reseeded per frame and raises a WARN (so `render.py video` refuses), during setup INFO.

**Song and beats.** `HP.T(ref)`; `HP.beat(x)` (edit s of beat x); `HP.beatSong(x)`; `HP.beatInfo(i)` (flags); `HP.beatAt(t)`
(fractional beat at edit t: phase = x - floor(x)); `HP.beatsIn(t0, t1, {step: 1 | 0.5 | 0.25, where: 'snare' | [...] | fn, from, to})`
-> `[{i, t, song, section, kick, snare, ...}]` (only beats the cut plays); `HP.songAt(t)`, `HP.editAt(s)`; `HP.sectionAt(t)`
(prelude, breath, riff, verse1, chorus, refrain, god, instrumental, verse2); `HP.vocalAt(t)`; `HP.hits` (the normalised file).

**Camera** (`#cam`; everything not `overlay`). `HP.cam.hit(t, amp px, decay)` (the legacy shake), `HP.cam.punch(t, amount, decay)`
(zoom impulse, +amount), `HP.cam.spin(t, deg, decay)`, `HP.cam.jolt(t, dx, dy, decay)`, `HP.cam.add(fn(t) -> {dx, dy, rot, zoom})`
(continuous, t-pure), `HP.cam.at(t)`. Impulses decay exponentially; on rotation the camera zooms just enough to cover the frame
(EDL `"camera": {"cover": false}` turns that off). `HP.flash(t, opacity, decay, color)`. Per-item beat bumps stay as `kicks`.

**Registry.** `HP.register(type, spec | class)`: a spec is `{build(item, HP), load?(item, HP) (async), layout?(item, HP),
prepare?(item, t, HP) (async), draw(item, t, HP), texts?(item, HP), ownMotion?, overlay?}`; a class extends `HP.Item`. The item
(`HP.Item`) has `d` (the EDL object), `id`, `t0`, `t1`, `el` (its layer div), `enter`/`exit`, `theme`, and helpers
`item.lt(t)`, `item.life(t)` (0..1), `item.canvas(css?)` -> `{cv, ctx}` (a full-frame canvas in its layer; clear and redraw it in
`draw`), `item.svg(attrs?)`, `item.attach(node)` (a node elsewhere, e.g. a `<g>` in a shared svg, that shows/hides and fades
with the item), `item.mark(t, what)`, `item.imagery(el)`, `item.active(t)`. Without `ownMotion` the layer gets the standard
enter/exit envelope (fade, slam, rise, ...); every item also takes `bg`, `hit`, `shakes`, `kicks`, `flash`, `z`, `overlay`,
`enabled`, `skipIn`, `verified`, `_note` as before. A later registration of a type replaces an earlier one (INFO).
`HP.registerFX(name, fn | {build(ev, HP), draw?(ev, t, HP)})`; `HP.on('setup' | 'built' | 'ready' | 'frame' | 'post', fn)`;
`HP.layoutDefaults(obj)`; `HP.css(text)`, `HP.loadCSS(href)`.

**EDL `fx` list** (beat effects, top level): `[{"id", "fx": name, "at": <time>} | {"fx": name, "on": "hb:0..31" (inclusive) |
["hb:0", 3.2, ...] | {"from": "hb:0", "to": "hb:31", "every": 1 | 0.5, "where": "snare" | ["kick", "accent"], "skip": [i]}, ...params}]`.
Core fills `ev.times` (edit s) and `ev.beats` (the beats with their flags, when `on` was given in beats) and marks every time.

**Layers and stacking.** Items stack in EDL order (later on top) unless `z` is set. Shared full-frame layers:
`HP.shared('paint')` -> `{cv, ctx}` (2D canvas, cleared before every frame; items paint into it in EDL order) and
`HP.shared('ink', 'svg')` -> `{svg}` (persistent DOM: show/hide your nodes with `item.attach`). A shared layer stacks where an
EDL item `{"type": "layer", "id": "paint", "kind": "canvas" | "svg"}` sits; undeclared ones go on top of `#cam`. `HP.layers`
= `{stage, cam, fx, flash, top}`.

**Text metrics** (canvas, fonts loaded before `build`). `HP.text.font({family, weight, size, style})`, `HP.text.measure(str, font,
tracking)`, `HP.text.wrap(str, font, maxW, {lh, tracking, balance})` -> `{lines: [{text, w, y, words: [{w, x, width, i}]}], width,
height, lh}`, `HP.text.fit(str, font, maxW, maxH)`, `HP.text.words(str)`. Fonts on the page: IBM Plex Mono 400-700, Newsreader
(variable, roman + italic), Unbounded (variable); add more to `HP.FONTS` before setup (a module can push to it at load).

**Assets** (all decode-awaited before the first frame). Paths are relative to `render/video/` (`cache/<id>/...`) or project-rooted
`song/...`, `research/...`, `brand/...` (render.py serves those three folders). `HP.assets.image(src)` -> Promise<img>,
`HP.assets.imageNow(src)` (sync, in `draw`), `json(src)`, `text(src)`, `svg(src)` (a parsed `<svg>`), `frames(folder)` -> a footage
sequence `{meta, count(), frameAt(lt, speed), get(n), now(n), prepare(n)}` (await `seq.prepare(n)` in your item's `prepare(t)`),
`HP.assets.track(promise)`. Footage is prepared by `prep_clips.py`: any item with `"prep": "clip"` (src, in, t0/t1, speed, crop |
srcFocus/srcZoom, grade, box | frame) or `"prep": "image"` is extracted to `cache/<id>/` like a clip/image item. No keying (rev2).
`HP.memo(key, fn)` caches a pure result (a baked stroke, a bled word: the key must determine it); `HP.offscreen(w, h)`.

**Vendored libraries.** `HP.lib.rough.canvas(cv, key)`, `.svg(svgEl, key)`, `.generator(key)`: rough.js with a seed derived from
`key` and the shape's arguments unless you pass `seed` (for boil use a key with `HP.boil(t)`); `HP.lib.rough.raw`.
`HP.lib.freehand.getStroke(points, opts)`, `.toPath(outline)`, `.path2d(outline)`. `await HP.lib.mathjax.load()` (in `load()`;
~150 ms) then `HP.lib.mathjax.svg(tex, {px, display, color})` -> `{svg, w, h, baseline}` (px-sized; glyphs are `<path>`s; the
GRPO objective typesets in ~65 ms). Other modules' exports: `HP.lib.legacy`, `HP.lib.paint`, `HP.lib.kandinsky`, `HP.lib.beatfx`,
`HP.lib.charts`, `HP.lib.equations`, `HP.lib.text`, `HP.lib.screens`.

**For the checks.** `item.texts()` returns `[{text, reveal: 'words' | 'chars' | 'highlight' | 'stroke' | 'none', role: 'main' | 'meta'}]`
(every main text over 4 words needs a reveal; keep visible words as DOM text so the checks can read them). `item.imagery(el)` /
`HP.markImagery(el)` declares footage/images. `item.mark(t, what)` / `HP.mark(t, id, what)` declares a beat event. Page probes:
`window.__beats(step, t0, t1)`, `window.__sched()`, `HP.probe.frame(t)`, `HP.probe.items()`.

**New EDL top-level keys.** `fx` (above); `hits` (another hits file); `finalHold: [t0, t1]` (the closing cover hold, exempt from
the imagery rule); `camera: {cover}`.

## Determinism and performance
`render(t)` depends only on `t` and the EDL: no `Math.random` (trapped), no wall-clock, no CSS transitions/animations (disabled on
the stage), no state carried from the previous frame (draw from scratch; cache only pure results with `HP.memo`). Check with
`python3 render/video/check/regress.py det test-<module>` (frames in order vs. reverse order in a fresh page: identical, apart from
Chromium's image-decode cache moving a few antialiased edge pixels of rotated images, mean ~0.001).
Budget: `render.py video` captures through the DevTools protocol (about 90 ms a frame at 1080x1920); legacy frames draw in
~10 ms; full renders run 0.12-0.19 s/frame on this box, target <= 0.35 s/frame, so a module may spend up to ~150 ms on its
heaviest frames. Measure with `render.py video <edl> --from S --to S` (prints s/frame). `--workers N` splits frames across N
Chromium pages (output is byte-identical) but gives no gain while another workflow shares the 4 cores.

## Checks (render/video/check/; outputs in check/out/, git-ignored with the rest of the renders)
- `render.py beats <edl> --from S --to S [--eighths] [--cols N]`: the strip, one frame per beat (first frame at/after it), labelled
  with the beat index, song time, section, frame and flags; bar downbeats framed.
- `beatcheck.py <edl> --render | --video file.mp4 [--video-start S] [--from S --to S] [--eighths]`: per beat, the change across it
  (frames 2 before vs 2 after: `mad`, `edge` flips, `local` = strongest 270x240 tile), what is scheduled on it, `weak` beats
  (mad < 6 and edge < 0.04 and local < 24; bars x2), dead stretches (consecutive-frame change < 0.6 for > 6 frames). JSON + PNG.
- `coverage.py <edl> [--from --to] [--step N]`: imagery in every frame (outside `finalHold`), reveal mode of every text over 4
  words, lyric 3-gram overlaps with song/full-map.json (only "it's brutal out here" while sung, song 71.5-74.2), text in the
  safe zone (x 60-1014, y 250-1574; right rail x > 930 for y 1000-1600 clear). JSON. DOM-level, fast (~500 frames in 3 s).
- `regress.py snap|compare <edl> DIR`: lossless stills before/after an engine change (mean |diff| < 1/255 per frame);
  `regress.py det <edl>`: determinism.
Before handing in a module: `regress.py compare` on long and short (legacy must not move), `det` on your test EDL, a `beats`
strip, `beatcheck.py --render`, `coverage.py`.

zones, avoid, calm, skip, map, no, barFlash}]` (or an `fx` entry `{"fx": "beatfx", "on": ...}`). Every beat gets a role from
song/hits.json (`crash` (hits.json crashes), `bar`, `fill` (hits.json fills), `backbeat` (snare), `beat`, `off` (8ths);
`vocalOn`/`vocalOff`) and per role one VISIBLE effect (guaranteed every beat) plus a camera move, weighted per pattern, seeded by
track id and beat, never the same as the previous beat's in the same slot. Patterns: `riff`, `verse`, `chorus` (= `refrain`),
`prelude`, `god`, `outro`, `calm`. `grid: "pulse"` runs on hits.json `prelude_pulse` (the prelude has no tempo-locked pulse).
`calm: "auto"` (default): the 0.4 s after a headline/screen/quote/chart/equation/caption item enters gets only grain, ticks and
small punches; tint and invert become a flash while footage or a fact is on screen. Visible effects: `splat`, `splatS`,
`droplets`, `stamp`, `scribble`, `tick`, `grain` (drawn on the paint layer, so never on the facts), `tint`, `invert`, `flash`,
`jump` / `burst` (the kand pieces; drawn effects instead when no kand item is active); camera: `punch`, `shake`, `snap`, `spin`,
`jolt`, `zoom` (anticipation). Drawn effects land in `zones` (default the frame margins) away from `avoid` rects and every kand
item's pieces and wordmark. Each effect also works alone as an `fx` entry (`{"fx": "stamp", "on": "hb:0..7"}`).
**Performance notes.** Zoom and rotation impulses use `HP.cam.add` sources that switch off below 0.35 px / 0.04 deg (core's
impulses keep a sub-pixel transform alive ~a beat). Any scale/rotation on `#cam` made Chromium repaint every layer (+250 ms a
frame); `fx/beatfx.js` therefore promotes the camera (now `HP.cam.promote()`, see **Integrator**: core resets the camera's compositor layers before every frame, so promotion no longer makes frames depend on render order) when an EDL has a beat track (legacy EDLs are untouched;
moving it into teaser.html is the integrator's call). Measured here (shared box): test-paint 0.2-0.25 s/frame steady with the
promoted camera, heaviest beats ~0.45; a static cover 0.085.

### `net`
Common: `kind`, `ground` (`dark` / `cream` / none), `cam`, `labels` (true), `splats` (true: on bar downbeats, placed where the
camera was on that beat).
- `kind: "mlp"`: a real sigmoid MLP 144-16-16-10 (seeded weights) reading a digit (`digit` 3, rendered from Newsreader italic,
  12x12 `grid`). The first pass is honestly wrong (`wrong` 8: the output biases are tilted), then one real gradient step
  (BP1-BP4, `eta` grown until the net says the target) fixes it. `infer` (times: input, h1, h2, output: one layer per beat;
  pulses travel along the edges and arrive ON the beat), `backprop` (times: output error, then the deltas back, in orange/red),
  `update` (edges thicken/thin by the real step), `infer2` (the corrected pass), `pulseOn` (times: a wave through all layers
  in a beat, edges flash, output nodes pop), `idle` (true: faint dots stream along edges between beats). Layout `flow:
  "right"` (3Blue1Brown-style; default) or `"down"`; `layerGap`, `pixel`, `edges` (7 strongest per node); `cam {yaw, pitch,
  dist, fov, orbit, step, target, cx, cy}` (a hand-rolled perspective projection: orbits continuously and steps on each layer
  beat); `layerNames`, `predPos`.
- `kind: "attention"`: `tokens`, `next`, `nHeads` (4), `heads` (times: one head per beat; arcs flicker in, weights from a
  seeded causal softmax per head; a "previous token" and a "first token" head), `tokensAt`, `predictAt`, `rowY`, `tokenPx`.
  Draws the causal Q/K grid of glowing dots under the row and circles the predicted token.
- `kind: "tower"` (3D hero, three.js WebGL): `tokens`, `next`, `blocks` (3), `nHeads` (4), `infer` (times: embed, attention
  and MLP of each block, output = 2 x blocks + 2 stages; the camera flies down with the wavefront and swings to the firing
  sub-block, heads fan out like cards, skip arcs carry a pulse over each block, the residual stream is a yellow river with
  vectors swimming down it, logits stand up as bars and the predicted token lands), `backprop` (times, 2 x blocks + 1:
  the river turns orange and flows up, each block flashes orange as the gradient passes, then shows updated weights),
  `wideAt` (the camera pulls back over the whole tower), `cam {yaw, pitch, dist, fov, orbit, lead, attnX, mlpX, roll, wideDist,
  wideYaw, widePitch, wideDur}`, `glScale` (0.5: the 3D renders at 540x960 and is scaled up; pencil outlines, tags and splats
  stay full resolution), `cell`, `blockGap`, `particles`, `fan`.
  WebGL here is SwiftShader (software): deterministic (`regress.py det` passes), the 3D costs ~90-130 ms a frame at
  `glScale` 0.5 (~350 ms at 1.0); full frames with the tower run ~0.35-0.45 s/frame on this shared box. If WebGL is missing
  the item WARNs (render.py video then refuses).

### Gotchas found while building
- `HP.lib.paint.makeSplat` memoises the splat (shape AND position) by its seed/key: a splat whose x/y follows a moving camera
  must use a position fixed for its life (computed at the splat's beat) and put that position in `key`, or the first frame
  rendered decides where it sits (history-dependent; `regress.py det` caught it).
- MathJax positions some glyphs with their own `transform` (e.g. the letters of `\log`): never overwrite it (equations.js
  composes with it).
- Reset every DOM node a frame may hide (opacity 0 before its time), or a reverse-order render shows it early.
- Item layers of these types set `isolation: isolate`, so their internal z-indexes never climb over later EDL items.

### Transitions
EDL top level `"transitions": [{id, at, dur (beats), type, out: [item ids], in: [item ids], lead, ...params}]`, or per item
`"enterFx": type | {type, dur, lead, at, ...}` (in: [this item], at its t0) / `"exitFx"` (out: [this item], at its t1).
- `at` is the beat the transition's IMPACT lands on; the window is `[at - lead * D, at + (1 - lead) * D]`, D = `dur` beats.
  Each type has its own default `dur` and `lead` (below), so a hard cut in the EDL (out.t1 = in.t0 = the beat) becomes a
  transition just by listing it.
- The outgoing items stay visible until the window ends and the incoming ones from its start (their own `t0`/`t1` are untouched,
  so footage frames and speech cues keep their timing; footage shows its first/last prepared frame outside its life). Their
  cut-side envelope (`exit` of out, `enter` of in) becomes `cut` (`keepEnv: true` keeps it). Types with their own out/entry
  animation (builder C's `screens` `out`, `panel` `entry`/`out`) should be set to `"cut"` on the side a transition handles.
- Common params: `flash` (opacity or `{opacity, decay, color}` on the impact), `shake` (camera hit px), `punch` (camera zoom; see
  determinism below), `ground` (colour | `false`: the frame colour put UNDER the content of the layers a type moves as whole
  frames, default `look.ground`, so a transparent card layer folds/slides/opens as a full sheet; only the bottom layer of a group
  gets it), `rect` (`[x, y, w, h]` or `"item"`: the area fold/shatter/pageturn treat as the page, default the full frame).
| type | dur, lead | what | params |
|---|---|---|---|
| `fold` | 1.25, .5 | origami: the outgoing sheet folds in half along a crease (its paper back in a palette colour, lit, with a cast shadow and the crease line), the half-sheet flies off, the incoming one unfolds out of its own back with a small overshoot | `axis` `v` (vertical crease, the right half folds) \| `h`; `mode` `both` \| `away` (the incoming is already under) \| `in` (it unfolds over the outgoing); `crease` px; `back` colour; `persp` (2200); `fly` |
| `zoomthrough` | 1.5, .62 | the camera pushes into a detail of the outgoing frame (log-space zoom, the detail drifting to the centre); the incoming frame is inside that detail behind a painted portal ring and opens to the full frame; speed lines | `focus [x, y]` (default the out item's rect centre), `r` (detail radius px, 120), `shape` `circle` \| `rect`, `rim` colour, `lines` |
| `whip` | 1, .5 | whip pan (out accelerates off, in decelerates in; skew + horizontal streaks) or spin zoom (rotate + scale, radial streaks); motion blur by ghost copies at earlier positions (no CSS blur: too slow here) | `mode` `pan` \| `spin`, `dir` 1 \| -1, `dist` (1500), `deg` (110), `ghosts` (3), `streaks` |
| `illuminate` | 1, .5 | a band of light sweeps along the plane's 22 deg, light leaks bloom from the corners in the cover's warm colours, the frame blows out to paper white ON the beat and clears onto the incoming frame | `colors` (`orange`, `pink`, `yellow`), `angle` (22), `sweep` |
| `shatter` | 1.5, .12 | cracks race out from the impact along Voronoi edges just before the beat, then shards (seeded per transition, denser near the impact) fly, spin, tumble in 3D and fall, each shaded by its tilt with a lit edge; the incoming frame is underneath | `n` (16), `impact [x, y]`, `speed`, `gravity`, `spin`, `tumble`, `persp`, `edge`, `cracks` |
| `particles` | 2, .5 | the outgoing frame breaks into a halftone, the dots leave as paint particles (coloured from its own pixels, trails and droplets) that swirl round the middle and land on a halftone of the incoming frame, which then fills in | `grid` (cell px, 44), `swirl` (turns), `colors` (fallback palette), `trail`, `rectIn` |
| `paintwipe` | 1, .45 | `cover` (default): HP.lib.paint's bristle bands paint over the frame, the cut hides under them ON the beat, the bands tear away; `matte`: the incoming frame is painted in through the bands' silhouettes, bristles over the edges | `style`, `n` (4), `angle` (-8), `colors` (`pink`, `violet`), `dir` |
| `iris` | 1, .3 | the incoming frame opens out of a Kandinsky shape that spins as it grows, with a painted rim (and the cover's second offset ring for circles); `close`: the outgoing frame closes into the shape | `shape` `circle` \| `ring` \| `square` (15 deg) \| `nabla` \| `band` (22 deg), `c [x, y]`, `mode` `open` \| `close`, `rim` colour (default by shape), `spin` (90), `pair` |
| `pageturn` | 1.5, .6 | the outgoing page turns over a hinge, curling (a chain of strips, each turning a little further), paper back past 90 deg, shading on the fronts, its shadow on the page beneath | `hinge` `left` \| `right`, `strips` (6), `curl` (55 deg), `persp` (3200), `back` |
`HP.lib.transitions`: `register(name, {dur, lead, order, ground, defaults, build?, apply(tr, t, u, X)})` for new types (`X.outs`,
`X.ins`: fresh copies of the layers this frame; `X.clone(el)`, `X.ovl()` the overlay canvas above them), `add(spec)`, `list`,
`camPunch(t, amt, decay)` (a zoom impulse with a 0.35 px cut-off), `itemRect(item)`, `voronoi(key, rect, n, focus)`,
`cloneLayer(el)`, `setStyle(el, prop, v)` (undone before the next frame), `paintRing`, `speedLines`, `project`, `rotP`, `about`.
**How it stays t-pure:** a `post` hook (after every item has drawn the frame) hides the involved layers and works on fresh
copies made from this frame's pixels (`swapLayer`/`cloneLayer` copy every canvas), so no layer keeps Chromium raster state from a
scaled or rotated earlier frame; an item in two overlapping transitions (the "in" of one, the "out" of the next) chains: the
second takes over the first one's copy (`swapLayer`; the black hole's swallow uses it too); layers are reordered when the
outgoing one must leave on top; light, paint, rims and particles go on an
overlay canvas inserted just above the pair. A `frame` hook removes all of it before the next frame draws. Cost: a clone ~5 ms
(plus its canvases), shatter = n clones; CSS filters on full-frame layers cost 60-150 ms each here and are not used.

## Integrator (11 Oct 2026): what changed when the modules were put together
All thirteen modules (plus `kandclip.js`) load together on every EDL with no clashes (`long`, `short` and the 15 test EDLs load and
render with no page error); `regress.py compare` on `long` and `short` against the architect's baseline stays at 0.0000.

**Camera promotion is now deterministic (fx/core.js, fx/beatfx.js).** Builders A, C and D all found that `#cam { will-change:
transform }` (needed for speed: zoom/rotation frames are ~1.6x faster promoted) made pixels depend on the frames rendered before
(Chromium keeps a promoted layer's raster scale and its descendants' composited state; screenshot cards and DOM text came out

and `renderAsync(t)` starts every frame of a promoted EDL by dropping #cam's compositor layers (`display: none` for two animation
frames), so each frame is rastered from scratch at its own scale. test-singularity and test-screens in vs. reverse order: worst
0.0005 / 0.0024 (was 1.44 / 0.12); cost ~+60 ms a frame on camera-heavy content (test-paint frames 60-150: mean 278 ms vs 217 for
the old, order-dependent promotion and 354 unpromoted). `?camreset=0` turns the reset off for measuring. With promotion on, a zoom
within 2e-4 of 1 and a rotation under 0.01 deg count as none (the tails of decaying impulses). `render(t)` (sync, the probes)
is unchanged; pixels come from `renderAsync` (render.py, the check tools).
