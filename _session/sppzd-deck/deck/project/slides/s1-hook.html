Background

Data is still largely curated on the model's behalf

Today

Pretraining is driven by “scaling pretraining on ever more data”, yet the data is “still largely curated on the model's behalf” (Abstract)

Curation today: data curation, data-mixture design, hand-designed synthetic generators (p.1)

This paper: zero data

Proposal: let the model “learn to generate the data most useful for its own improvement” (Abstract)

Setting: generator and learner both randomly initialized; all learner data comes from self-play (p.2)

No natural data in any gradient update; natural validation loss (DCLM, DNA) chose hyperparameters (p.8)

Scope: models below 25M params, 4K context (p.15); max budget 34.36B tokens (p.8); loss in bits per byte

Test: does zero-shot loss on natural data improve predictably with self-play compute? (Abstract)
