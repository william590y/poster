About 1.5 minutes. App. E and Table 4 (pp.29-30). Slide claims with sources: 8 Brainf*ck instructions < > + - [ ] . , plus end token F; Turing complete with the 8 alone (App. E, pp.29-30). Byte cells mod 256 on a circular tape; unmatched brackets are no-ops, so every string runs (App. E, p.30). ',' reads i.i.d. uniform bytes from a random tape ω (App. E, p.30), so one program is a distribution over outputs (Sec. 2.1, p.4). Output y = first T bytes emitted, zero-padded if the program halts early. Example (deterministic, no ','): +++[>+.<-]F emits y = (1, 2, 3, 0, ..., 0) (App. E, p.30). 10 macros, shared by all methods and baselines (Table 4, p.30); the slide table shows four that appear in Table 1 programs (C, L, V, X). Generator logits: 8 + 10 + F (Sec. 2.3, p.7); 19 total is my sum. Macros are expansions into pure Brainf*ck, idioms "frequently used in human written Brainf*ck programs" that "appear to increase the efficiency of self-play in preliminary experiments" (p.30). The paper notes that all methods use the same augmented alphabet. Do not show the printed Table 4 crop: row C prints '[->+>+«]', a typo for '<<'. Other macros: Z [-], R [->+<], N [-<->], G [>], H [<], W [[-]>+<]. R also appears in the quadratic program. For randomness, Table 1's Fibonacci program S,[[.C>.C>] starts with ','. My re-implementation gives 1,1,2,3,5 only when the random byte is 1; otherwise r*(1,1,2,3,5,...) mod 256. So Table 1 outputs are one tape draw. Not reported: T, L, step budget, tape length. [mine] T is probably 4,095, since PCFG rows are 4,095 bytes (App. H) and the context is 4,096 with an O prefix. The crop shows the p.30 for-loop example.
