Background

Self-play: search where the learner can still learn

The program space is enormous, and “whether a sequence is useful changes as the learner improves” (p.2)

So the generator adapts: RL toward programs “near the frontier of the learner's current capabilities” (p.2)

Rejected reward: difficulty

“a program can be made arbitrarily difficult without containing useful structure”, e.g. by injecting random bytes (p.5)

Used instead

Reward programs whose learner gradients align with the learner's own parameter movement (Eq. 2, in Method)

Reward chosen by search at small scale (p.5); ablated at 1M params (Table 5, p.31)

“By teaching, we learn.”
